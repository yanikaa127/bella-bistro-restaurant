# Bella Bistro Website

A responsive restaurant landing page built with HTML, CSS, and JavaScript.

## Preview locally
1. Download or clone this repository.
2. Open `index.html` in your web browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.

Your website will be published at the GitHub Pages URL shown in the Pages settings.

## Customize
- Edit restaurant details, menu items, prices, and contact information in `index.html`.
- Change colors, fonts, and layout in `style.css`.
- The reservation button currently opens an email draft. Replace the email address with your own.
- Photos are loaded from Unsplash and require an internet connection.

All visible website content is written in English.
